# 实验结果与泛化分析

最后核验：2026-08-11

## 1. 已验证主结果

结果对应 V1：三分支、两层 88 通道、486,838 参数、固定 SGD `lr=0.01`。

| 指标 | 数值 |
|---|---:|
| Best validation accuracy | 94.425% |
| Test accuracy | 95.15% |
| Macro precision | 95.22% |
| Macro-F1 | 95.16% |
| Weighted-F1 | 95.16% |
| Test correct/total | 1,903/2,000 |

该结果使用 segment-level 平衡 split，不是新录音或新船只隔离结果。

## 2. 分类别结果

| 类别 | Precision | Recall | F1 |
|---|---:|---:|---:|
| Cargo | 91.94% | 95.80% | 93.83% |
| Passenger | 98.10% | 92.80% | 95.38% |
| Tank | 94.22% | 94.60% | 94.41% |
| Tug | 96.63% | 97.40% | 97.01% |

最大混淆是 Tank→Cargo 21 个和 Cargo→Tank 18 个。Tug 最易识别；Passenger precision 高但
recall 最低，说明模型预测 Passenger 较保守。

## 3. 严格隔离到底是多少

### 3.1 有证据的 recording-disjoint 结果

历史轻量 CNN 先划分原始 WAV，再生成片段：

| Partition | 原始录音数 | 3 s 候选片段数 |
|---|---:|---:|
| Train | 426 | 39,331 |
| Validation | 91 | 9,088 |
| Test | 92 | 8,445 |

同一路径不会跨集合。代表性最优配置为 4 kHz log-Mel、branch 24、fused 128、约 250,889
参数：

| 指标 | 数值 |
|---|---:|
| Best validation accuracy | 69.43% |
| Test accuracy | **69.67%** |
| Test Macro-F1 | **68.91%** |
| Test Weighted-F1 | 69.51% |

历史 STFT Transformer＋MAE 在 recording-level 测试上为：

| 指标 | 数值 |
|---|---:|
| Test accuracy | 68.79% |
| Test Macro-F1 | 67.94% |

这些历史结果与 95.15% run 的采样率、模型和样本策略不同，因此不是严格单变量实验；但它们
能说明新录音泛化明显更难。

### 3.2 当前没有 vessel-disjoint 数字

DeepShip 描述包含 265 艘不同船只，本地却有 609 条录音，说明一艘船可能对应多个 WAV。
原始 metafile 含船名但没有统一 vessel ID/MMSI；当前已将 603 条录音清洗为 247 个规范名称
组，另有 6 条 Tank 录音因缺少唯一元数据保持未解析。

因此，对“训练集和验证集绝对没有同一艘船”最准确的回答是：**当前项目没有该协议下的可信
性能数字**。69.67% 是最接近的录音级隔离结果，但不能冒充船只级隔离。

## 4. 为什么片段级能到 95.15%

同一长录音的片段共享水听器、海况、距离、背景和稳定线谱。随机分到多个 partition 后，模型
可能学到录音身份相关特征。16 kHz、更平衡的样本和模型变化也有影响，所以不能把约 25 个
百分点差距全部归因于泄漏，但 split 是最主要的风险变量。

## 5. 历史路线

| 路线 | 协议 | 代表 Accuracy | 结论 |
|---|---|---:|---|
| STFT Transformer＋MAE | recording-level | 68.79% | 复杂但不稳定 |
| STFT/log-Mel 融合 Transformer | recording-level | 49%～65% | 融合未形成稳定互补 |
| 早期轻量 CNN | recording-level | 69.67% | 选择 CNN 主线 |
| V1 88 通道 CNN | segment-level | 95.15% | 已验证片段级结果 |
| V2 32→64＋ECA＋98 head | smoke only | 无 | 当前待训练 |

MAE 重建被遮盖谱块不等于学习类别判别特征；更多分支和特征也会增加小数据下的优化难度。

## 6. 下一步如何得到船名组隔离结果

1. 使用 `recording_vessel_manifest.csv` 中 603 条可靠映射，排除 6 条未解析录音；
2. 校验每条 recording 恰好属于一个 `vessel_key` 和一个类别；
3. 使用 GroupShuffleSplit/GroupKFold 按 `vessel_key` 分组；
4. 所有片段继承 vessel partition；
5. 固定 manifest，并报告 vessel 数、recording 数和片段数；
6. 用 V1/V2 同一特征、同一训练配置公平比较；
7. 至少运行 3 个 seed，报告均值和标准差；
8. 同时报告片段级和整条录音聚合指标。

该结果应称为 vessel-name-disjoint。若要声称严格物理船只隔离，仍需由发布方或 AIS 提供
MMSI/IMO 映射；否则最严格的已核验身份单位仍是规范船名组。
