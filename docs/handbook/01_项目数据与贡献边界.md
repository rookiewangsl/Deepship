# 项目、数据与贡献边界

最后更新：2026-08-11

## 1. 项目目标

输入单通道水下船舶辐射噪声，输出四类：Cargo、Passenger、Tank、Tug。完整流程为：

```text
DeepShip WAV
→ 扫描与标签组织
→ 3 s 非重叠切片
→ 重采样到 16 kHz
→ 64×94 log-Mel
→ 三分支 MA-CNN-A
→ 四分类指标与混淆矩阵
```

项目当前是离线音频分类系统，不包含阵列波束形成、流式推理、嵌入式部署或独立单 WAV
Demo。

## 2. 数据规模

本地可用数据为 609 条 WAV、约 47.22 小时：

| 类别 | 录音数 | 非重叠 3 s 片段数 |
|---|---:|---:|
| Cargo | 109 | 12,801 |
| Passenger | 191 | 15,410 |
| Tank | 240 | 14,762 |
| Tug | 69 | 13,495 |
| 合计 | 609 | 56,468 |

DeepShip 公开描述包含 265 艘不同船只和多个录音。本地四个 `*-metafile` 含船名、日期、时间
等信息，但没有统一的 MMSI/IMO 字段，且存在截断船名、Tank 编号重置和少量缺行。

当前清洗结果为：609 条 WAV 中 603 条得到可靠船名映射，6 条 Tank 录音保持未解析；规范化后
得到 247 个可用于分组的名称键。这个数字是“可区分名称组”，不是重新核验后的物理船只总数。

## 3. 主数据协议

从每类候选片段中固定 seed 42 抽取 5,000 段：

| Partition | 每类 | 总数 |
|---|---:|---:|
| Train | 3,500 | 14,000 |
| Validation | 1,000 | 4,000 |
| Test | 500 | 2,000 |

这是 segment-level split。同一原始 WAV 的不同片段可能跨 train/validation/test，所以 95.15%
只表示该片段级协议下的表现，可能高估新录音和新船只泛化能力。

## 4. 录音级与船只级隔离

三个概念不能混用：

| 协议 | 隔离单位 | 当前是否有结果 |
|---|---|---|
| Segment-level | 仅片段不重复 | 有，95.15% |
| Recording-level | 同一 WAV 不跨集合 | 有，历史 CNN 69.67% |
| Vessel-level | 同一船名组的全部 WAV 不跨集合 | 映射已准备，尚未训练 |

历史 recording-level split 包含 426 条训练录音、91 条验证录音和 92 条测试录音，并保证路径
不重叠。但由于 609 个录音来自 265 艘船，不同录音可能对应同一 vessel，所以不能把这个
69.67% 直接称为“同一艘船完全隔离”。

当前可执行的保守 vessel-name-disjoint 协议使用：

```text
recording path → canonical vessel name → vessel_key
```

再按 `vessel_key` 分组划分，所有同名船只的录音和片段继承同一个 partition；6 条未解析录音
应从该实验排除。由于 `QUEEN OF` 等船名被截断，同名归组采取保守策略，可以降低泄漏风险，
但不能替代 MMSI/IMO 级物理身份核验。

## 5. log-Mel 特征

单样本处理：

```text
读取 3 s waveform
→ 按真实 source_sr 重采样到 16 kHz
→ 修正到 48,000 samples
→ MelSpectrogram(power=2)
→ AmplitudeToDB
→ [1,64,94]
```

| 参数 | 数值 |
|---|---:|
| `sample_rate` | 16,000 |
| `n_fft/win_length` | 1,024/1,024 |
| `hop_length` | 512 |
| `n_mels` | 64 |
| `center` | True |

94 帧来自：

```math
1+\left\lfloor\frac{48000}{512}\right\rfloor=94
```

项目分析过 STFT、LOFAR、MSC 和 log-Mel。当前可复现主线只保留 log-Mel；LOFAR/MSC 没有
形成同完整度训练代码，因此应表述为特征方案分析，不夸大为正式消融。

## 6. 贡献边界

| 内容 | 准确归属 |
|---|---|
| DeepShip | 公开数据集 |
| log-Mel、非对称卷积、ECA | 公开方法 |
| 数据扫描、切片、manifest 和外置存储 | 项目工程实现 |
| 三分支结构、通道配置和分类头适配 | 论文启发下的项目调整 |
| 训练、早停、指标和图表 | 项目工程实现 |
| Segment/recording split 对比 | 项目实验分析 |

推荐面试表述：

> 我独立完成了 DeepShip 长音频到分类指标的完整 PyTorch pipeline，并在公开多尺度非对称
> 卷积与 ECA 思路上进行三分支轻量化适配。旧版模型在片段级协议下达到 95.15%，同时我
> 发现录音级隔离后历史准确率约 69.67%，说明评测协议对结论影响显著。我进一步从原始
> metafile 清洗出 603 条录音到 247 个规范船名组的映射；在完成按组重训前，我不会把录音级
> 结果误称为严格船只级泛化。
