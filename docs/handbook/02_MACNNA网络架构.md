# MA-CNN-A 网络架构

最后更新：2026-08-11

## 1. 当前 V2 总体结构

```text
Input [B,1,64,94]
 ├─ Branch k=8  ─┐
 ├─ Branch k=16 ─┼─ Add → ECA-style Attention → 98-ch Head → GAP → FC(4)
 └─ Branch k=32 ─┘
```

## 2. 单分支四层卷积

每个分支的 `k` 分别为 8、16、32：

| 层 | 卷积核 | 通道 | Stride | 输出尺寸 |
|---|---|---:|---|---|
| 输入 | - | 1 | - | `[B,1,64,94]` |
| Conv 1 | `1×k` | `1→32` | `(1,2)` | `[B,32,64,48]` |
| Conv 2 | `k×1` | `32→32` | `(2,1)` | `[B,32,33,48]` |
| Conv 3 | `1×k` | `32→64` | `(1,1)` | `[B,64,33,49]` |
| Conv 4 | `k×1` | `64→64` | `(1,1)` | `[B,64,34,49]` |

每层均为 `Conv2d(bias=False) → BatchNorm → ReLU`。偶数核使用 `padding=k//2`，所以 stride 1
时对应维度增加 1；三个分支规则一致，因此最终可以相加。

## 3. 为什么用非对称卷积

方形卷积参数核面积为 `k²`，而 `1×k` 与 `k×1` 组合约为 `2k`。它还能分别建模：

- 时间方向：线谱是否持续、短时模式如何变化；
- 频率方向：低频能量分布和机械谱线关系。

时间轴与频率轴物理意义不同，这种分方向建模比把 Mel 图完全当普通图像更有水声先验。

## 4. 多尺度与加法融合

`k=8/16/32` 提供不同感受野。每个分支只把 Conv 4 的 64 通道输出用于主融合：

```math
F_{fused}=F_8+F_{16}+F_{32}
```

Add 后仍为 64 通道；若 concat 会变为 192 通道，后续参数明显增加。Add 的代价是分支身份
信息被混合，需要注意力与后续卷积重新整理。

## 5. 六路 ECA 风格注意力

三个分支的 Conv 3 和 Conv 4 均作为注意力来源，共六路：

```text
[B,64,H,W] → GAP → [B,1,64]
→ Conv1D(k=3) → Sigmoid → [B,64,1,1]
```

六组权重相加后乘到 `F_fused`。当前没有除以 6 或 softmax，所以组合权重不仅能抑制，也可
放大通道。

ECA 核长由通道数计算：

```math
k=odd\left(\left|\frac{\log_2(C)+1}{2}\right|\right)
```

当前 `C=64 → k=3`。这个 k 是通道轴邻域，与分支的二维核 `8/16/32` 没有直接关系。

## 6. 分类头

```text
Attention output [B,64,34,49]
→ 1×8 Conv, 64→98       [B,98,34,50]
→ 8×1 Conv, 98→98       [B,98,35,50]
→ Global Average Pool   [B,98]
→ Linear, 98→4          [B,4]
```

GAP 避免大尺寸 flatten FC，使分类参数不依赖空间大小。

## 7. 三个结构版本

| 项目 | 论文 | V1 已测 | V2 当前 |
|---|---|---|---|
| 分支 | 8/16/32/64 | 8/16/32 | 8/16/32 |
| 每分支 | 32/32/64/64 | 88/88 | 32/32/64/64 |
| 注意力来源 | 8 路 | 6 路 | 6 路 |
| 分类卷积 | 1×8/8×1, 98 | 1×3/3×1, 88 | 1×8/8×1, 98 |
| 参数量 | 约 1.00M | 486,838 | 532,166 |
| 本项目正式 Accuracy | - | 95.15% | 尚无 |

V2 比 V1 多 45,328 个参数，约增加 9.31%。它更接近论文分支深度和分类头，但少一个 64
尺度分支，且尚未正式重训，所以不能继承 V1 的 95.15%。

## 8. 面试速答

**为什么三个分支？** 用不同感受野同时建模细粒度和稳定宽尺度时频结构，并比四分支更轻。

**为什么 Add 不 Concat？** 保持 64 通道，减少后续参数和内存。

**ECA 为什么不用两层 FC？** Conv1D 不压缩通道维，参数少，并保留邻近通道交互。

**当前模型准确率？** V2 尚无正式结果；95.15% 属于 V1。
