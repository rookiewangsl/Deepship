# 面试问答与公式速查

最后更新：2026-08-11

## 1. 一分钟项目介绍

> 我做的是 DeepShip 单通道船舶辐射噪声四分类，处理 609 条、约 47.2 小时长录音。我完成
> 了 16 kHz 重采样、3 秒切片、64×94 log-Mel、三分支非对称卷积、ECA 通道注意力到训练
> 评估的完整 PyTorch pipeline。V1 48.7 万参数模型在片段级测试集达到 95.15%；录音级隔离
> 的历史 CNN 约 69.67%，揭示了同源片段对结果的影响。当前 V2 改为 32→64 四层分支和
> 98 通道分类头，约 53.2 万参数，但尚未继承旧成绩。

## 2. 高频问题

### 为什么是 64×94？

64 是 Mel filter 数。3 秒 16 kHz 为 48,000 samples，`center=True、hop=512`：

```math
1+\lfloor48000/512\rfloor=94
```

### 为什么选择 log-Mel？

它压缩动态范围和高频维度，对低频保留较细分辨率，适合船舶低频机械线谱，也比完整 STFT
输入更小。LOFAR/MSC 只完成方案分析，当前正式 pipeline 使用 log-Mel。

### 为什么非对称卷积？

`1×k` 与 `k×1` 分别建模时间持续性和频率分布，大核参数项由 `k²` 降到约 `2k`，同时在
两个方向间加入 BN/ReLU 非线性。

### 为什么三个尺度？

8/16/32 提供不同局部感受野，兼顾细节与稳定宽尺度结构；比论文四分支少一个 64 尺度，
换取更低参数和计算。

### 为什么 Add 不 Concat？

Add 保持 64 通道；Concat 会变成 192 通道并增加后续分类头成本。代价是分支身份混合。

### ECA 的 k 和分支 k 是一回事吗？

不是。ECA `k=3` 是长度为 C 的通道序列上的 Conv1D 邻域；分支 `8/16/32` 是时频二维核。

### ECA 核长怎么得到？

```math
k=odd\left(\left|\frac{\log_2(C)+1}{2}\right|\right)
```

当前 C=64，所以 k=3。它不降维，比 SE 两层 FC 更轻。

### 注意力用了什么？

三个分支各取 Conv 3 和 Conv 4，共六路 64 通道特征。每路 GAP＋Conv1D＋Sigmoid，六组
权重相加后乘主融合特征。

### 当前模型准确率是多少？

V2 尚无正式准确率。95.15% 属于 V1 486,838 参数模型；V2 为 532,166 参数，只完成 smoke
test。

### 严格数据隔离性能是多少？

若“严格”指同一 WAV 不跨集合，历史 CNN test Accuracy 69.67%、Macro-F1 68.91%。若指
同一艘船完全不跨集合，当前没有结果，因为本地 609 条录音没有 vessel ID 映射。

### 为什么 recording split 低很多？

新录音具有不同背景、海况、距离和工况，模型不能利用同录音稳定特征。历史配置也不同，
所以不能把全部差值精确归因于泄漏。

### MAE 为什么没成为主线？

遮盖重建更偏低层谱结构，不一定学习四类判别特征；原始录音规模也有限。历史最好约 68.79%
recording-level，复杂度更高但没有稳定超过 CNN。

### 为什么用 SGD？

它与参考训练协议一致，momentum 0.9。当前没有 Adam 的公平对照，所以不声称 SGD 必然更优。

### Warmup＋cosine 有什么作用？

Warmup 降低随机初始化阶段大步长不稳定，cosine 在后期逐渐减小学习率。它是 V2 的后续调整，
尚未证明带来准确率提升。

### 项目是否已经适合嵌入式部署？

约 53.2 万参数且采用非对称卷积、Add、ECA 和 GAP，属于面向轻量化设计；但尚无 MACs、
目标硬件延迟、内存和量化结果，不能说已完成部署。

### 如果继续做，最优先是什么？

先获得 vessel ID 并建立 vessel-disjoint split；再用 V1/V2、固定 LR/当前 scheduler 做公平
矩阵实验，最后补单 WAV/整录音推理和目标硬件测量。

## 3. 核心公式

STFT：

```math
X(k,m)=\sum_n x[n]w[n-mH]e^{-j2\pi kn/N}
```

Mel 映射：

```math
m=2595\log_{10}(1+f/700)
```

Conv2D 参数量：

```math
P=C_{in}C_{out}K_hK_w
```

GAP：

```math
z_c=\frac{1}{HW}\sum_{h,w}F_{c,h,w}
```

Softmax：

```math
p_i=\frac{e^{z_i}}{\sum_j e^{z_j}}
```

Cross-entropy：

```math
L=-\log p_y
```

Precision / Recall / F1：

```math
P=\frac{TP}{TP+FP},\quad
R=\frac{TP}{TP+FN},\quad
F1=\frac{2PR}{P+R}
```
